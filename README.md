### About me
I design, build, and operate production systems — from the database and API to the frontend and the server it all runs on. My core is **C# / ASP.NET Core** with **Clean Architecture**, and I own the infrastructure side too: Linux, Docker, reverse proxies, and CI/CD.

###  In production
- **[DevHub AI]** — An LMS platform I built from scratch and operate. **10,000+ exams** delivered so far.
- **[SafeExam]** — An in-lab university exam system with anti-cheating and exam-gating workflows.
- **Identity Platform** — A central identity system acting as the login hub for the university's platforms.

###  Featured projects
- **Root2Route** — A multi-tenant B2B commodity & live auction platform (.NET 10, Angular 21). It uses CQRS and Optimistic Concurrency for race-free bidding, with real-time updates over SignalR.
- **Sales & Installment Management System** — A financial engine with a FIFO payment-allocation waterfall, ROWVERSION concurrency, and EF Core audit interceptors.
- **ICPC NATU Community Platform** — Contest operations and automated scoring. It uses EF Core + Dapper, SQL window functions for leaderboards, and Codeforces API ingestion.
